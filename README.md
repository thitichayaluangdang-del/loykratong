# 🪷 เว็บลอยกระทงออนไลน์ ๒๕๖๙ (Loy Krathong Online Festival)

เว็บแอปพลิเคชันสำหรับร่วมสืบสานประเพณีลอยกระทงในรูปแบบดิจิทัล รักษ์สิ่งแวดล้อม ปลอดภัยต่อระบบนิเวศน์ทางน้ำ

## ✨ จุดเด่นและฟังก์ชันการทำงาน

- 🌸 **เลือกแบบกระทงได้ ๖ รูปแบบวิจิตร**:
  1. *กระทงใบตองวิจิตร* - ประเพณีดั้งเดิม ดอกดาวเรืองและกล้วยไม้
  2. *กระทงบงกชสวรรค์* - ดอกบัวสีชมพูผลิบาน เสริมบารมี สงบ ร่มเย็น
  3. *กระทงเต่าขนมปังรักษ์โลก* - ขนมปังรูปเต่าน้อยน่ารัก ให้อาหารปลา ย่อยสลาย 100%
  4. *กระทงกะลาสายธาร* - มนต์เสน่ห์กระทงสายล้านนา แสงเทียนสว่างไสว
  5. *กระทงมงคลเศรษฐี* - ประดับกลีบทองคำ เสริมโชคลาภเงินทอง
  6. *กระทงพฤกษาสวรรค์* - มวลบุปผาหลากสีสันสดชื่นเบิกบาน
- 🕯️ **เลือกแสงเทียนมงคล**: แสงทองอบอุ่น, แสงชมพูเสน่หา, แสงฟ้าบริสุทธิ์, แสงมรกต
- ✍️ **กรอกชื่อ & คำอธิษฐาน**: พร้อมปุ่มลัดเลือกคำอธิษฐานยอดนิยมได้ในคลิกเดียว
- 🏮 **ปล่อยโคมลอยยี่เป็ง**: เขียนคำขอพรลงบนโคมลอย ปล่อยขึ้นสู่ฟากฟ้า
- 🎆 **จุดพลุเฉลิมฉลอง**: คลิกบนท้องฟ้าเพื่อจุดพลุ หรือเปิดระบบจุดพลุอัตโนมัติ
- 🔊 **ระบบเสียงเสมือนจริง (Web Audio API Synthesizer)**: เสียงน้ำไหล เสียงจุดพลุ และดนตรีไทยบรรเลงชวนผ่อนคลาย (ไม่มีการโหลดไฟล์เสียงภายนอก โหลดเร็ว 100%)
- 💬 **คลิกอ่านคำอธิษฐานกระทง**: คลิกกระทงที่ลอยในสายน้ำเพื่ออ่านคำอวยพรและการ์ดคำอธิษฐาน
- 📱 **Responsive Design**: แสดงผลสวยงาม รองรับทั้งมือถือ แท็บเล็ต และคอมพิวเตอร์

---

## 🚀 วิธีการทดสอบรันในเครื่องด้วย Node.js

```bash
# 1. รันเซิร์ฟเวอร์
npm start

# หรือ
node server.js
```

จากนั้นเปิดเบราว์เซอร์ไปที่: `http://localhost:3000`
